把 Excel 里的彩色文字换成颜色标签

拖入或选择本地表格。单元格里带了字体颜色的文字会写成 <color=#RRGGBB>文字</color>。这段文字如果已经有 color 标签，就只更新标签里的颜色值，不再套一层。

  • 整格上色整段文字包进一个 color 标签。
  • 只上一截同一个格子里只有一部分变色时，只标记那一段。
  • 已有标签保留 <b> 等其他标签，只改 color 的颜色值。
  • 纯黑默认跳过黑色和 Excel 默认文字色不加标签。背景色、条件格式不处理。
